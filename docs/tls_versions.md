# TLS/DTLS versions supported

Lightway server and client supports the latest TLS and DTLS protocols only, which is TLS 1.3 and DTLS 1.3.

### Quick Summary

|                 | TLS     | DTLS               |
| --------------- | ------- | ------------------ |
| Lightway Server | TLS 1.3 | DTLS1.3            |
| Lightway Client | TLS 1.3 | DTLS1.3            |
